HTML

acrónimo en inglés de HyperText Markup Language («lenguaje de marcado de hipertexto»), hace referencia al lenguaje de marcado utilizado en la creación de páginas web. Este estándar que sirve de referencia para el software que interactúa con la elaboración de páginas web en sus diferentes versiones.


a continuacion veremos algunos ejemplos de codigo HTML 


       <!DOCTYPE html>
<html>
<head>
    <title>Hola Mundo</title>
    </head>
<body>
    <h1>Hola Mundo</h1>
</body>
</html>

tambien podemos encontrar una convinacion de teclas para llegar a las funciones mas rapido tambien llamados atajos.

ctrl + s Para guardar.
ctrl + o Para abrir el explirador de archivos.
ctrl + N crea un nuevo archivo.

La primera versión informal de HTML, conocida como HTML 1.0, se popularizó alrededor de 1993. Contenía un conjunto básico de etiquetas paracrear páginas web simples con encabezados, párrafos, listas e hipervínculos.
